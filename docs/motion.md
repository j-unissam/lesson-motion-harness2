# motion.md

움직임 성격: **통통 팝**. 레퍼런스 값 그대로 쓴다. 부품은 살짝 커졌다 돌아오며 튀어나오고, 장면은 둥근 원이 퍼지며 바뀌고, 카메라는 고정이다.
레퍼런스: `references/pre/생물과환경_생태계_수업영상_내레이션.mp4` (1920×1080 · 30fps · 2분 24.5초)

> 재는 방법: 프레임마다 앞 프레임과의 차이를 계산해 움직이는 구간을 찾았다. 그 구간을 1/30초(1프레임) 또는 1/15초 간격 필름으로 펼쳐서 시작 · 끝 프레임을 셌다.
> 출처 표기 `pre 00:43.53–43.90` = 레퍼런스 43.53초부터 43.90초까지 잰 값.
> **눈대중** 표시가 붙은 값(튐 크기, 곡선 모양)은 프레임 사진을 보고 어림한 것이다. 나머지는 프레임 수를 센 값이다.

## 2. Semantic (뜻이 있는 움직임)
기본 값을 조합해 이름을 붙인 것이다. 장면표에서는 이 이름으로 부른다.

| 이름 | 하는 일 | 조합 | 출처 |
|---|---|---|---|
| `pop-in` | 새 것이 "통" 나타남 | scale 0.3→1, `dur-pop`, `ease-pop`, 투명도 0→1 (처음 0.1s) | pre 00:43.53–43.90, pre 01:24.97–25.30 |
| `pop-in-small` | 작은 알약(판정 · 역할 · 예/아니요)이 "톡" 나타남 | `pop-in`과 같고 길이만 `dur-tick` 0.13s | pre 01:12.43–12.57 "소비자" 알약 |
| `pop-out` | 할 일 끝난 것이 사라짐 | scale 1→0.4, 투명도 1→0, `dur-exit`, `ease-in` | pre 00:06.37–06.67 |
| `slide-in` | 카드가 옆에서 들어옴 | `slide-from` → 제자리, `dur-slide`, `ease-out`, 투명도 0→1 | pre 00:07.27–07.53, pre 00:20.80–21.60 |
| `drop-in` | 새 등장 생물이 위에서 내려앉음 | `drop-from` → 제자리 0.15s + 되튐 0.2s | pre 01:12.03–12.37 |
| `fly-to` | 그림이 분류 카드 안 제자리로 날아감 | `fly-arc`, `dur-move`, `ease-inout` (먼저 출발점에 `pop-in`) | pre 00:23.00–23.43 (출발점 등장 pre 00:23.57–23.70) |
| `draw` | 화살표 · 선이 한쪽에서 그려짐 | 길이 0→100%, `dur-fast`, `ease-out`, 머리가 앞장섬 | pre 01:12.77–13.00 |
| `text-in` / `text-out` | 아래 설명 띠 · 글 줄이 나타남 / 사라짐 | 투명도만, `dur-fast` | pre 01:12.77–13.03 / pre 01:11.70–12.00 |
| `focus` | 지금 말하는 것 짚기 | 대상 `highlight-scale` + `highlight-border`, 나머지 `dim`, `dur-tick` | pre 02:05.60–05.73, pre 01:49 |
| `inflate` / `deflate` | 그림이 부풀거나 줄어듦 (기체의 부피 변화) | 크기만 천천히 바꿈, **1.5s**, `ease-inout`. 바닥에 붙은 그림은 아래쪽을 기준으로 키운다 | 레퍼런스에 없음 → 선생님이 정함 (2026-11-15, gas-3-2-to-3-3) |

`scene-wipe` 색 (덮는 원 두 개): 레퍼런스는 장면마다 다르다. 00:19 노랑→주황, 00:40 초록, 01:06 파랑, 01:30 주황·노랑, 02:01 초록 (콘택트 시트에서 확인). → 첫째 원은 **노랑** `color-highlight`, 둘째 원(과 단색 · 열기)은 **다음 장면의 역할 색**을 쓴다 (00:19 노랑→주황처럼, 2026-11-15 선생님 확인). 원이 퍼지는 중심은 화면 가운데 근처다.

## 5. 카메라
| 항목 | 값 | 출처 |
|---|---|---|
| 확대 · 축소 | **없음** | 영상 전체 (프레임 차이에서 화면 전체가 같이 움직이는 구간이 원 전환 말고는 없음) |
| 좌우 · 상하 이동 | **없음** | 같음 |
| 장면 바꾸기 | 컷이나 카메라 이동 대신 `scene-wipe`만 | pre 00:19.2 · 00:40.2 · 01:07.2 · 01:31.2 · 02:01.2 |
| 짚기 | 카메라를 움직이는 대신 `focus`(대상 키우기 + 나머지 흐리기) | pre 01:49, pre 02:05.6 |

> 바탕 부품을 영상보다 10% 크게 만든 것(`design.md`)은 나중에 카메라를 쓰고 싶을 때를 위한 여유다. 이 움직임 성격(통통 팝)에서는 카메라를 쓰지 않는다.

## 하지 말 것
- 카메라 확대 · 이동 · 흔들기: 레퍼런스에 없다
- 회전하며 나타나기, 튕기는 횟수 2번 이상: 레퍼런스는 한 번만 살짝 튄다
- 0.5s보다 긴 튀어나오기: 레퍼런스에서 가장 긴 것이 0.4s다 (큰 카드 미끄러지기 0.8s만 예외)
- 화면 전체를 흐리게 바꾸는 크로스페이드 전환: 장면 전환은 원 전환만 쓴다
- 글자를 한 글자씩 타이핑하듯 나타내기: 레퍼런스는 줄 단위로 나타난다
